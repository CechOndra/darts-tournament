# Stage memes (drop-in folder)

Each meme pops up on the stage after the visit that triggers it. The `.svg` files here are
placeholders: put your own image next to them with the same name and it is used instead
(`.png`, `.jpg`, `.gif` or `.webp`; the first one found wins, the placeholder is last).

| File name           | Suggested meme                    | Shown when                                              |
| ------------------- | --------------------------------- | ------------------------------------------------------- |
| `same-score`        | Spider-Man pointing at Spider-Man | Same 3-dart score as the opponent or your previous visit |
| `maximum`           | Leo cheers                        | 180                                                     |
| `ton-plus`          | Stonks                            | 100 to 179                                              |
| `bed-and-breakfast` | Bed and breakfast                 | Exactly 26                                              |
| `bust`              | This is fine (dog in fire)        | Bust                                                    |
| `all-miss`          | Visible confusion                 | 3 darts, 0 points                                       |
| `big-checkout`      | Galaxy brain                      | Checkout of 100+                                        |
| `bull-finish`       | Mic drop                          | Finishing on the bull                                   |
| `madhouse`          | Madhouse                          | Finishing on double 1                                   |

Optional sound: `<name>.mp3` plays with the meme (otherwise the admin can turn on spoken captions).

Keep images under ~500 KB. Everything in this folder is publicly downloadable from the site,
so only use images you are happy to publish.
