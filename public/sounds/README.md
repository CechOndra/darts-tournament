# Crowd soundboard recordings (optional)

Drop MP3 files here to replace the built-in generated sounds on the stage:

- `airhorn.mp3`
- `applause.mp3`
- `drumroll.mp3`
- `oooh.mp3`
- `boo.mp3`
- `fanfare.mp3`

Keep them short (1-4 seconds) and small (under ~200 KB each). Missing files fall back to the generated sound.
Note: everything in this folder is publicly downloadable from the GitHub Pages site.
