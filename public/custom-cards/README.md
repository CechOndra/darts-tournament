# Custom card artwork (optional drop-in folder)

Drop transparent-background PNGs here to override the built-in SVG/CSS card templates:

- `fut-bronze.png`, `fut-silver.png`, `fut-gold.png`, `fut-icon.png` — FUT player card frames (816 x 1000 portrait)
- `<card_id>.png` — Power Card art, e.g. `ALL_OR_NOTHING.png`, `SHOT_CLOCK.png`

Missing files are fine: the app always falls back to its self-contained templates.
