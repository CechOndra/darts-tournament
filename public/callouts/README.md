# Referee callouts (optional)

Drop short mp3 clips here. When a visit finishes, the stage plays the matching clip; with no clip the computer voice speaks as before.

- `<score>.mp3` for any score: `180.mp3`, `140.mp3`, `26.mp3`, ...
- `noscore.mp3` (zero or bust), `gameshot-leg.mp3`, `gameshot-match.mp3`

Keep clips 1-2 seconds. Everything here is publicly downloadable from the site.
